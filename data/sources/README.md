# Owner-supplied source archives

USDA FoodData Central archives are **not** in Git (multi-GB). Place them here,
or point `MACROS_SOURCE_DIR` at wherever they live:

```bash
export MACROS_SOURCE_DIR=~/Downloads/usda
```

Expected filenames:

- `FoodData_Central_foundation_food_json_2026-04-30.json`
- `FoodData_Central_sr_legacy_food_json_2018-04.json`
- `FoodData_Central_branded_food_json_2026-04-30_json.zip`
